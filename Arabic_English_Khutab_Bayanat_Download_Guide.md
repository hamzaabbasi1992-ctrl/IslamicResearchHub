# Arabic & English Khutab/Bayanat Download Reference Guide

Companion reference to `Arabic_Khutab_Bayanat_to_be_downloaded.csv` and
`English_Khutbah_Lectures_to_be_downloaded.csv` - full link lists and
notes per collection, for manual review before downloading. Nothing
here has been downloaded or verified byte-for-byte; links were located
via web search on 2026-08-10/11 and should be checked before use.

## Notes for whoever downloads these

- Every link above is an Archive.org **item page** (or, where noted, a direct file link) - open the page and check the "Files" list before assuming a specific format is present; the same item can bundle audio, video, and PDF differently per upload.
- Several collections (Muhammad Hassan, Al-Maghamsi, Khalid Yasin) are confirmed **audio/video only** - don't expect PDF/text from these without separate OCR/transcription work.
- Fan-made transcript sites (Yasir Qadhi's Seerah blog, Nouman Ali Khan collections) are unofficial and may have formatting/accuracy issues compared to the original audio.
